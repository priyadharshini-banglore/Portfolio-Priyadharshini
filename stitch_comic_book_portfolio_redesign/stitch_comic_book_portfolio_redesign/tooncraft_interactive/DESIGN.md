## Brand & Style

This design system expresses a vibrant, tactile, comic-strip aesthetic calibrated specifically for an AI and Full-Stack Developer portfolio. It rejects the sterilized, monochromatic conventions of standard engineering portfolios in favor of expressive exuberance, mechanical tactility, and dynamic visual narrative. 

The personality is energetic, clever, inventive, and deeply human. The interface conveys senior technical depth disguised as an interactive graphic novel, proving that high-performance engineering and lighthearted character can coexist seamlessly.

The aesthetic fuses Neo-Brutalism with Sunday comic printing techniques and 3D cartoon physical computing:
- **Neo-Comic Tactility:** Solid black ink containment lines, hard-edged offset drop shadows without blur, and satisfying press-state physics that compress on click.
- **Printed Matter Texture:** Subtle halftone dot arrays, paper-cream surfaces, tape strips, and speech bubble tails that bring digital UI into physical, tangible space.
- **Micro-Playfulness:** Asymmetrical rotations (-2deg to 3deg), hand-drawn decorative bursts, spark stars, and dynamic paint splashes that punctuate technical architecture diagrams and code showcases.

## Colors

The palette balances warm, low-fatigue newsprint canvases with punchy comic ink accents and candy pastels.

### Canvas & Surface Layers
- **Base Canvas (`#FAFAF7`):** Warm milk-white background that removes digital glare while preserving contrast.
- **Surface Elevation 1 (`#F5F3EF`):** Muted cream paper tint for secondary grouping containers and nested section panels.
- **Surface Elevation 2 (`#FFFDF8`):** Bright parchment surface for floating interactive cards, active popovers, and code blocks.

### Comic Inks & Accents
- **Comic Ink Black (`#18181B`):** The structural backbone. Used for crisp 2.5px borders, solid offset drop shadows, and high-impact typography.
- **Sunny Pop Yellow (`#FACC15` / Tint `#FEF08A`):** Primary action color, hero labels, key metric callouts, and star bursts.
- **Energetic Coral-Orange (`#FB923C` / Tint `#FED7AA`):** Secondary accent for interactive states, flame tags, and Git commit ribbons.
- **Sky Blue (`#38BDF8` / Tint `#BAE6FD`):** Tertiary indicator for AI models, API endpoints, and cloud infrastructure pills.
- **Grass & Mint Green (`#22C55E` / Tint `#BBF7D0`):** System health, production readiness, and active terminal indicators.
- **Bubblegum Pink (`#F472B6` / Tint `#FCE7F3`):** Playful sticker tags, interactive easter eggs, and speech bubble highlights.

## Typography

The typography leverages an energetic clash between high-flavor comic display headers and ultra-crisp geometric body copy. 

- **Display & Headlines (Bricolage Grotesque):** Set with high weights (700-800) and optical squeeze to deliver a punchy graphic novel tone. Headlines often employ uppercase treatments or subtle rotation for key phrases.
- **Body & Technical Specs (Plus Jakarta Sans):** Provides geometric precision, exceptional screen legibility, and high x-height. Keeps long-form case studies, architecture notes, and technical achievements crisp and readable.
- **Badges & Microcopy:** Always rendered in bold weights (700-800) with slight positive tracking to evoke screen-printed comic caption boxes.

## Layout & Spacing

The layout is built around a structured 12-column responsive grid framed by generous margins and distinct comic panel dividers.

### Layout Mechanics
- **Desktop (1024px+):** 12-column fluid grid, max-width 1280px, with 1.5rem gutters and 2rem outer canvas margins. Project grids utilize asymmetric spans (e.g., 7/5 splits) resembling classic multi-panel comic strips.
- **Tablet (768px - 1023px):** 8-column grid with 1.25rem gutters. Panels stack gracefully into 4-column balanced pairs.
- **Mobile (< 768px):** 4-column linear strip with 1rem gutters and 1.25rem outer margins. Stickers and pins scale down and maintain simplified offsets to prevent layout clipping.

### Section Dividers
Sections are separated either by solid 2.5px comic ink rules or by decorative zigzag/half-tone bandings rather than empty white gaps. Spacing between major showcase modules relies on generous vertical breathing room (`space-xl` * 2) to maintain distinct visual chapters.

## Elevation & Depth

This system discards soft ambient blur shadows entirely. Depth is created through crisp physical hard-stops and layered cutouts:

- **Level 0 (Flat/Canvas):** 0px offset with 2.5px solid Comic Ink border (`#18181B`).
- **Level 1 (Subtle Tactile / Chips):** `3px 3px 0px #18181B`. Used for active badges, filter tags, and interactive inline code snippets.
- **Level 2 (Standard Interactive / Cards):** `5px 5px 0px #18181B`. Standard state for project containers, navigation ribbons, and speech balloons.
- **Level 3 (Lifted Hero Elements):** `8px 8px 0px #18181B`. Reserved for floating modal dialogues, pinned tech stack banners, and featured case studies.

### Dynamic Interaction Physics
On pointer hover, interactive components translate -2px along both axes while the shadow expands from 5px to 7px (`7px 7px 0px #18181B`). On `:active` (click/press), the element collapses: `transform: translate(4px, 4px)` with the shadow shrinking to `1px 1px 0px #18181B`, simulating a physical mechanical switch.

## Shapes

The design system embraces a friendly, rounded-box visual geometry with intentional playful imperfections:

- **Primary Geometry:** 0.5rem (8px) border radius on cards, panels, and containers to balance organic comic art with interface stability.
- **Pill Geometry:** Buttons, chips, and notification counters frequently take full rounded capsule treatments (`rounded-full`) bound by solid 2.5px borders.
- **Decorative Additions:**
  - **Speech Bubble Arrows:** Triangular SVG cutouts with 2.5px borders appended to card edges.
  - **Rotational Jitter:** Badges, tape strips, and stickers feature fixed randomized angles (`-2.5deg`, `+1.5deg`, `-1deg`) to break the grid monotony.
  - **Masked Edges:** Halftone dot matrices and diagonal comic speed-stripes applied as interior corner accents on cards.

## Components

### Buttons
- **Primary Action Button:** Sunny Yellow background (`#FACC15`), 2.5px solid Comic Ink border, 0.5rem radius, offset shadow `4px 4px 0 #18181B`. Bold label with uppercase tracking. Hover pushes out to `6px 6px 0 #18181B`; active press translates down `(3px, 3px)` with shadow collapsing to `1px 1px 0 #18181B`.
- **Secondary Action Button:** Surface Parchment (`#FFFDF8`) with black label, identical border and mechanical hover physics.
- **Icon / Pin Buttons:** Circular containers (`44px x 44px`) housing hand-drawn micro-icons with 3px hard drop shadows.

### Project & Case Study Cards
- **Base Style:** Parchment cream surface (`#FFFDF8`), 2.5px solid ink border, 5px hard offset shadow.
- **Top Accent Banner:** Paint-stroke splash sweeps across the top-right header, tinted in Pastel Green, Pink, or Sky Blue.
- **Metadata Badges:** Pill-shaped tech stack tags pinned to the card bottom with `2px 2px 0 #18181B` shadow and 1px interior borders.

### Sticker Badges & Chips
- **Status Badges:** Small capsule indicators (`rounded-full`) featuring a glowing indicator dot (e.g., Mint Green for "Available for Projects"), rotated at `-2deg` or `+2deg`.
- **Speech Bubble Notes:** Cream or Pastel Bubblegum background with a directional tail pointing toward code snippets, delivering conversational engineering commentary.
- **Tape Strips:** Semi-transparent cream tape overlays (`rgba(255, 255, 255, 0.85)`) angled at `-3deg` on top of image corners.

### Input Fields & Controls
- **Text Inputs:** `#FFFDF8` background, 2.5px solid Comic Ink border, 4px inset shadow simulation on focus with Sunny Yellow background highlight on associated label tags.
- **Checkboxes & Radios:** Hand-drawn aesthetic check squares with heavy 2.5px ink outlines; checked state fills with vibrant Coral-Orange (`#FB923C`) and a bold black check mark.

### Terminal & Code Callouts
- **Code Panels:** Styled as a retro tech manual with deep ink black headers, primary-colored dot window controls (Red, Yellow, Green), crisp monospaced code formatting, and a comic-style speech annotation bubble from the "AI assistant."
